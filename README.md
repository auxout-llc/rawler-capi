# rawler-capi

A plain C ABI over [rawler](https://github.com/dnglab/dnglab) (the RAW decoding library of
dnglab), built as a dynamic library: `librawler_capi.dylib` / `.so` / `rawler_capi.dll`.

It exposes only what rawler does, without product-specific processing:

- open a RAW file and pick rawler's decoder (`rlc_open`, `rlc_check_supported`)
- generalized metadata: make/model, lens, EXIF exposure fields, dates, orientation (`rlc_metadata`)
- decode the sensor data (`rlc_decode`, optionally header only) and describe it
  (`rlc_image_describe`): sizes, u16/f32 samples, CFA pattern, black/white levels,
  as-shot WB, active area, default crop, orientation, color matrices with illuminants,
  BaselineExposure, AnalogBalance
- the raw bytes of DNG OpcodeList1..3 (`rlc_image_opcodes`), applying OpcodeList1 and the
  LinearizationTable with rawler's implementation
- rawler's demosaic algorithms on a caller-provided float mosaic (`rlc_demosaic`):
  PPG (Bayer), Markesteijn 1/3-pass and bilinear (X-Trans)

The header is `include/rawler_capi.h` (generated by cbindgen from `src/lib.rs`).
`rlc_abi_version()` returns the ABI version (currently 2); it changes with every
incompatible change, so a replacement library can be checked by its users.

## Build

```bash
cargo build --release                        # host
cargo build --release --target aarch64-apple-ios
```

Apple builds get the install name `@rpath/librawler_capi.dylib`, ELF builds the
SONAME `librawler_capi.so` (see `build.rs`), so that a program or library that links it
finds it next to itself.

## Conventions

- Functions return `RLC_OK` (0) or a negative `RLC_ERR_*` and write a message to `err`.
- Panics inside rawler are caught and returned as `RLC_ERR_PANIC`.
- Objects are created and freed by this library. A handle must not be used from two
  threads at the same time; separate handles are independent.
- `threads`: 0 = rayon's global pool (`RAYON_NUM_THREADS` or the CPU count), N > 0 = a
  pool of N threads owned by this library.
